# Прототип формы рейда

Запуск из корня проекта: `node prototypes/raid-create/server.cjs`.
Открыть `http://127.0.0.1:3210/`; заполненный пример — `/?example=filled`.
Одна адаптивная страница для desktop и mobile.

Это отдельный статический прототип: нет импорта приложения, чтения env, API или БД.
Все изменения живут в памяти вкладки и теряются при перезагрузке. Создать рейд —
демонстрационное действие. Шаблоны, участники, предметы и стадии условные; наборы
не описывают реальный дроп Freya или другого инстанса. Stage 3 первоначально пустая;
Stage 1/2 показывают только примеры расположения плиток. Stage меняется локально,
выбор участников/профилей, предметы и комментарии сохраняются.

Внешних запросов при открытии нет. Профессии используют существующие пользовательские
PNG из `public/game-icons/classes/`. Демонстрационные иконки предметов локально
сохранены из существующего источника приложения `https://l2db.info/uploads/images/icons/`:
weapon_vesper_cutter_i00, armor_t94_u_i01, etc_scroll_of_enchant_weapon_i05,
etc_scroll_of_enchant_armor_i05, etc_mineral_rare_i03, etc_codex_of_giant_i00.
Публичная доступность не означает свободную лицензию. Эти файлы используются
для локального просмотра прототипа; разрешение на их публичное распространение
здесь не устанавливается. Иконки не являются подтверждением состава/шанса дропа.
