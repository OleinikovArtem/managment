# F02. Справочник прокачки Soul Crystal (СА)

Цель: найти, с какого босса/инстанса качается нужный СА, до какого уровня и на каких условиях. Это справочник, а не учёт принадлежащих персонажу кристаллов.

Фича ещё не реализована. [Примеры данных](mock-data.json) относятся только к СА,
не загружаются приложением и не задают расписание существующего календаря.

## SA-01. Контракт правил и демонстрационные данные — этап 0

**Описание.** Подготовить записи, которые позже заполняются таблицей пользователя и ссылаются на существующие коды инстансов.

**Требования.**

- Поля: instanceCode, bossKey/отображаемое имя, тип/цвет кристалла при наличии ограничения, исходный и целевой уровень, условия, вероятность только если подтверждена, источник, версия/revision, demo/verified.
- Босс и инстанс — разные понятия: у одного инстанса может быть несколько боссов. Отсутствующий bossKey не связывать с именем инстанса автоматически.
- Неизвестная вероятность хранится как null и показывается «не указана», а не 0%/100%. Проверять положительные уровни и `targetLevel > fromLevel`; поддержка нескольких переходов — несколько записей.
- Условия сохраняются текстом до подтверждения структуры таблицы: квест, последний удар, состав и прочие ограничения не выдумываются.
- Нет строки → «Нет сведений», а не «СА не качается». Запрет прокачки, если он будет в таблице, должен быть отдельным явным фактом.
- Источники и серверная конфигурация обязательны для публикации как verified. Mock не изменяет каталог предметов и не создаёт реальные Item для кристаллов.

**Приёмка.** Все mock instanceCode разрешаются в `prisma/seeds/instances.json`; строки без источника не становятся verified. Неизвестные коды и неверные уровни показываются в preview и не применяются частично. Замена mock таблицей сохраняет связь с существующими инстансами.

## SA-02. Поиск и отображение — этап 1b

**Описание.** Раздел/вкладка «СА» в контексте инстансов с фильтром по инстансу и целевому уровню; поиск по боссу и названию.

**Требования.**

- Результат показывает «инстанс → босс → переход уровня → условия → источник». Есть переход в календарь выбранного инстанса.
- На карточке инстанса кратко видны доступные переходы; нет сведений и отсутствие результатов поиска различаются.
- Всем членам группы доступно чтение. Отдельный редактор общего каталога и массовый пользовательский upload не входят в scope; пополнение идёт контролируемым импортом.
- Demo-значения обозначены в списке и деталях; не смешиваются с проверенными без метки.

**Приёмка / E2E.** Фильтр целевого уровня возвращает нужный переход и его точные условия; поиск по боссу и инстансу работает; переход в календарь сохраняет выбранный инстанс. Пустой поиск не выглядит запретом прокачки. MEMBER не может подменить правила прямым запросом; own-инстансы другой группы не раскрываются. На 390 px читаются условия, всё доступно клавиатурой.

**Зависимости.** Только формат и каталог инстансов; финансовые сервисы и Telegram не требуются. Реальные игровые сведения ждут таблицы, сам интерфейс можно проверять на demo.
